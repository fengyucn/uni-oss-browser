# OSS Browser 1.19.1 社区版发布说明

## 概述

此版本是对原始阿里云 OSS Browser 的重大分支，将其转变为可连接到任何 S3 兼容对象存储服务的通用浏览器，支持：

- Amazon S3
- MinIO
- Ceph
- Wasabi
- DigitalOcean Spaces
- 阿里云 OSS（向后兼容）
- 腾讯云 COS
- 华为云 OBS
- 其他 S3 兼容服务

## 主要变更

### 通用 OSS 支持
- 将阿里云特定的 `ali-oss` 和 `aliyun-sdk` 依赖替换为通用的 `aws-sdk`
- 更新所有 API 调用以使用标准 S3 兼容接口
- 保持对阿里云 OSS 的向后兼容性

### 安全性增强
- 移除了启动时自动打开开发者工具的功能
- 改进了各种 OSS 服务的身份验证处理
- 添加了对自定义端点和区域的支持

### 用户体验改进
- 添加了常用 OSS 服务端点下拉列表，便于配置
- 改进了登录工作流和错误处理
- 增强了连接到各种服务的文档

### 技术增强
- 更新了构建系统和依赖项
- 改进了代码结构和可维护性
- 为社区使用添加了全面的文档

## 破坏性变更
- 移除了不属于标准 S3 的阿里云特定功能
- 将默认端点更改为 AWS S3 格式
- 移除了启动时自动打开调试工具的功能

## 如何升级
1. 从 GitHub releases 下载最新版本
2. 解压并替换现有安装
3. 配置您首选的 OSS 服务端点
4. 使用您的服务凭据登录

## 已知问题
- 某些阿里云特定功能可能无法与其他服务一起使用
- 某些高级功能在不同的 OSS 服务提供商之间可能有所不同
