# OSS Browser 1.19.1 Community Edition Release Notes

## Overview

This release represents a major fork of the original Alibaba Cloud OSS Browser, transforming it into a universal S3-compatible Object Storage Service browser that can connect to any S3-compatible service including:

- Amazon S3
- MinIO
- Ceph
- Wasabi
- DigitalOcean Spaces
- Alibaba Cloud OSS (backward compatible)
- Tencent Cloud COS
- Huawei Cloud OBS
- And other S3-compatible services

## Key Changes

### Universal OSS Support
- Replaced Alibaba Cloud specific `ali-oss` and `aliyun-sdk` dependencies with generic `aws-sdk`
- Updated all API calls to use standard S3-compatible interfaces
- Maintained backward compatibility with Alibaba Cloud OSS

### Enhanced Security
- Removed automatic opening of developer tools on startup
- Improved authentication handling for various OSS services
- Added support for custom endpoints and regions

### User Experience Improvements
- Added common OSS service endpoints dropdown for easier configuration
- Improved login workflow with better error handling
- Enhanced documentation for connecting to various services

### Technical Enhancements
- Updated build system and dependencies
- Improved code structure and maintainability
- Added comprehensive documentation for community use

## Breaking Changes
- Removed Alibaba Cloud specific features that are not part of standard S3
- Changed default endpoint to AWS S3 format
- Removed automatic debug tool opening on startup

## How to Upgrade
1. Download the latest release from GitHub releases
2. Extract and replace your existing installation
3. Configure your preferred OSS service endpoint
4. Log in with your service credentials

## Known Issues
- Some Alibaba Cloud specific features may not work with other services
- Certain advanced features may vary between OSS service providers
